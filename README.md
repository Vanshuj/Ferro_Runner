# Ferro Runner

An endless side-scrolling browser game built with pure HTML5, CSS3, and vanilla JavaScript. Flip the polarity of a magnetic ball between **North (N)** and **South (S)** to navigate between magnetic rails and collect gems.

## Play Online

Once GitHub Pages is enabled, the game is live at:
https://vanshuj.github.io/Ferro_Runner/

## Controls

- **Flip Polarity:** `Space`, `ArrowUp`, Click, or Tap
- **Pause / Resume:** `P` or the **Pause** button
- **Assist Mode:** Toggle the checkbox for slower speed and gentler magnetic forces

## Run Locally

Open `index.html` directly in any modern browser, or start a local server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
